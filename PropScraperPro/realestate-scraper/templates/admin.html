📖 Setup Guide

1
Get Groq API key

Go to console.groq.com → API Keys → Create key. It's free. Paste it above.

2
Create a Google Cloud project

Go to console.cloud.google.com → New Project → Enable the Google Sheets API.

3
Create a service account

IAM & Admin → Service Accounts → Create → Download JSON key. Paste the JSON above.

4
Share your Google Sheet

Open your Sheet → Share → paste the service account email (from the JSON). Give Editor access.

5
Add the Sheet ID

Copy the ID from the URL: docs.google.com/spreadsheets/d/[SHEET_ID]/edit

6
Run a scrape & sync

Go to Scraper → launch a job → come back here → click "Sync Unsynced Listings".
